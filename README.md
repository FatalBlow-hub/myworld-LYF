# 方块世界（Minecraft Web）

> 📅 2026-09-24 | 状态: 🚧 进行中 | 标签: #游戏 #threejs
> **摘要**：用浏览器就能玩的简化版《我的世界》

## 怎么玩

```bash
npm install
npm run dev
```

然后打开终端里显示的网址（一般是 http://localhost:5173）。

## 操作（纯键盘，不用鼠标）

| 按键 | 作用 |
| --- | --- |
| ↑ / ↓ | 前进 / 后退 |
| ← / → | 左转 / 右转 |
| 8 / 2 | 向上看 / 向下看 |
| P | 挖掘 / 攻击 |
| L | 放置方块 |
| 空格 | 跳跃 / 水中上浮 |
| M | 开门 / 关门 |
| 4 / 6 | 物品栏：选上一个 / 下一个方块 |
| ESC | 暂停 |

## 文件说明

- `src/main.ts` — 游戏入口
- `src/config.ts` — 所有可调参数（区块大小、视距、血量规则）
- `src/core/` — 游戏主循环
- `src/world/` — 世界数据与地形生成
- `src/render/` — 画面渲染
- `src/player/` — 移动、物理、血量
- `src/interact/` — 挖方块、放方块
- `src/ui/` — 菜单和屏幕上的界面
- `docs/architecture.md` — 架构设计文档
