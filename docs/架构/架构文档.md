# 架构文档 — 方块世界（Minecraft Web）

> 📅 2026-09-24 | 状态: 🚧 进行中 | 标签: #架构 #游戏 #threejs
> **摘要**：Three.js 网页版方块游戏的模块划分、依赖方向与核心机制设计

## 技术栈

- **Vite + TypeScript + Three.js**：浏览器打开即玩，无需安装运行环境
- 纯前端单页应用：无后端、无数据库；存档后续可用 localStorage
- 纹理：代码程序化生成（Canvas 画 16×16 像素图），不依赖外部素材

## 玩法范围

- 第一人称：走动 / 跳跃 / 游泳 / 转弯；键盘挖方块、放方块、开关门/箱/炉
- 键盘移动视角 + 鼠标操作背包/容器格子（左键拿放）
- 开局二选一模式（菜单选择）：
  - **生存模式**：显示血条；溺水、摔落扣血；血空死亡重生；物资靠挖
  - **创造模式**：无血条，任何伤害不扣血也不会死；背包可拿全部方块
- 格子制背包：快捷栏 9 + 储物 27 + 装备 4 + 合成 2×2，按 9 打开
- 合成与拆解：材料进 2×2 出成品；成品单独放入可拆回原材料
- 容器：箱子（27 格存储）、熔炉（沙子→玻璃、圆石→石头、生肉→熟肉）
- 动物：牛/猪/羊闲逛，打死掉生肉，吃生肉扣血、熟肉回血
- 灵魂草：约每千个草方块刷一个，挖掉得本体，可拆解为草方块+灵魂蓝颜料
- 灵魂蓝颜料可染：箱子/木台阶/石台阶/熔炉 → 灵魂蓝变体（灵魂火熔炉烧蓝火）

## 模块职责与依赖方向

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `config` | 全部魔法数字集中处 | 无 |
| `world` | 方块数据与地形生成 | `config` |
| `render` | 把世界数据画到屏幕 | `world`（只读）, `config` |
| `player` | 输入、物理、生命 | `world`（碰撞查询）, `config` |
| `interact` | 挖/放方块 | `world`, `render`（相机） |
| `ui` | 菜单与 HUD | `player`（读血量）, `config` |
| `core/Game` | 主循环，组合以上模块 | 全部 |

**依赖铁律**：只允许 `ui / interact / player → render / world → config`，`Game` 在最顶层。禁止 `world` 反向依赖上层，禁止循环依赖。

## 核心机制设计

### 1. 世界 = 切好的乐高底板（Chunk）

- 世界按 **16×16（水平）× 64（高）的竖柱区块** 切分（`config.ts` 的 `CHUNK.SIZE` / `CHUNK.HEIGHT`；v1 曾误写为 16×16×16，2026-10-15 订正），每个区块一个 `Uint8Array`（每格存 1 字节方块 ID）
- 只生成玩家附近的区块（视距由 config 控制，v1 默认 4 个区块半径）
- 好处：内存小、改一个方块只需重建所在区块的网格

### 2. 渲染 = 只画看得见的面（面剔除）

- `ChunkMesher` 遍历区块内每个非空气方块，**只给挨着空气的面**生成三角形
- 一张纹理图集 + UV 偏移，所有方块共用 1 个材质 → 每个区块仅 1 次绘制调用
- 方块被挖/放时，重建本区块网格（邻接区块在边界上也要重建）

### 3. 地形生成

- 二维噪声（简易 value noise，自己实现，无外部依赖）生成高度图
- 高度 < 海平面 → 填水；表面草方块，下面泥土/石头；随机撒树
- 用固定种子，保证每次进游戏世界一致

### 4. 物理 = 盒子碰方块（AABB）

- 玩家是一个长方体盒子，每帧按速度移动后，逐轴与周围方块做 AABB 碰撞回退
- 水中：重力减弱、阻力增大、可按空格上浮

### 5. 合成 / 拆解 / 容器

- `Recipes.ts` 一张表定全部：`RECIPES`（材料→成品）、`UNCRAFT`（特殊拆解）、`SMELT`（熔炉）
- `matchCraft(counts)`：先对合成表（合成优先），再判断单格成品拆解 → 返回消耗与产出
- 2×2 只按"种类+数量"匹配，不看摆放位置
- 箱子/熔炉内容存在 `World.chests` / `World.furnaces`（按坐标键），拆掉容器会把存货撒地上
- 熔炉每帧走 `updateFurnaces(dt)`，进料格有可燃物就推进度，成品进右侧格

### 6. 血量与溺水

- `Health` 模块统一收伤害事件：`fall`（摔落）、`drown`（溺水）、`attack`（预留怪物接口）
- 生存模式：正常扣血，血 ≤0 → 死亡 → 重生点复活满血
- 创造模式：同一套事件照常发出，但 `Health` 直接忽略 → 满足"不扣血也不会死"
- 溺水规则：头没入水中开始耗氧（氧气条显示），氧气耗尽后每秒扣 1 颗心

## 游戏循环（每帧）

```
输入(Controller) → 物理移动+碰撞(Physics) → 溺水/摔落结算(Health)
→ 挖放方块(BlockPicker) → 重建脏区块网格(ChunkMesher) → 渲染(Renderer) → HUD 刷新
```

## 扩展预留

- `attack` 伤害接口 → 后续加怪物不用改架构
- `World` 序列化接口 → 后续 localStorage 存档
- 方块注册表 → 加新方块只改 `Block.ts` + 纹理
