# M3b — 大厅排队与随机匹配（小岛生存 B2 B3 B4 B5 B6）

## 目标

把大厅接上联机：进大厅自动排队；排到队首弹选择框；选「随机去陌生岛屿」花 2 个铁锭，服务端随机分配一座苹果/桃子/橙子副本岛（1/3 各一座），玩家进入副本岛。副本岛无怪物、无动物、无沙漠雪地地形。

> 本期不做「去好友的岛」（按钮在，点了提示即将开放，M4 做），不做双重验证与挖掘权限（M5 做）。

## 已拍板的决策（照做）

| 项 | 决策 |
| --- | --- |
| 排队条件 | **必须联机**。未连接服务器时进大厅只提示「未连接服务器，排队不可用」，不入队 |
| 场景三态 | `scene: 'island' \| 'hall' \| 'visit'`。`H` 键：island ↔ hall；**在 visit 里按 H 回 hall 并自动重新排队（队尾）** |
| 队首选择框 | 新建 `src/ui/HallMenu.ts`（overlay + 两个按钮 + 关闭），注册进 `PanelStack`，打开时世界暂停（与其它面板一致） |
| 选「随机陌生岛」 | 客户端先查背包铁锭 ≥ 2：不够 → 提示「铁锭不够，回到队尾」并重新 `hall.join`；够 → 本地扣 2 铁锭 → 发 `hall.random` → 收到 `hall.matched` 后进入副本岛 |
| 服务端职责 | 管队列与匹配：只允许**队首**发起 `hall.random`；分配 `islandId`（随机不重复）与 `islandType`（1/3 概率）；队列变化广播给所有人。**不校验铁锭**（权威校验是 M5 的活） |
| 副本岛地形 | 按 `islandId` 固定种子生成；**无沙漠、无雪地群系**；无怪物、无动物 |
| 副本岛收获 | 随身背包带走（离开副本岛时不清背包） |
| 离开副本岛 | 副本岛世界**直接丢弃不保存**；按 H 回大厅自动重新排队 |
| 好友岛按钮 | 本期点击提示「好友访友即将开放」 |

## 消息协议（追加到 `src/net/Protocol.ts` 与 `server/ws.mjs`）

| 方向 | 消息 | 说明 |
| --- | --- | --- |
| C→S | `hall.join` / `hall.leave` | 进/离队（重复 join 幂等） |
| C→S | `hall.ready` | 请求确认自己是否队首 |
| C→S | `hall.random` | 队首发起随机匹配（扣费已由客户端完成） |
| S→C | `hall.queue` | 广播：队列名单 + 「我在第几位」 |
| S→C | `hall.head` | 你是队首，可以选了 |
| S→C | `hall.matched` | `{ islandId, islandType }`，去副本岛吧 |
| S→C | `hall.error` | `{ msg }`：不是队首 / 队列已满等 |

## 验收标准

1. `npm run build` 通过（tsc 零报错）
2. `npm run server` + `npm run dev`，**两个浏览器标签页**都进大厅：两边都看到「队列：你排第 X 位」且名单一致
3. 只有一个人时：进大厅即队首，弹出选择框（两个按钮）
4. 有两个人时：后进的那个显示排队中，先进的那个弹选择框；先进者关掉面板后，队首自动转移给第二个（或提示他可以准备了）
5. 队首选「随机陌生岛」且背包有 ≥2 铁锭：扣掉 2 个，进入一座副本岛，HUD 提示岛类型；岛上**没有僵尸动物**，地形**没有沙漠雪地**（多试几次）
6. 铁锭不足时选「随机陌生岛」：提示铁锭不够并回到队尾
7. 副本岛里按 `H`：回大厅并自动排到队尾；再按 `H` 回自己的岛，自己的岛原样恢复
8. 副本岛里挖的东西在回自己岛后还在背包里
