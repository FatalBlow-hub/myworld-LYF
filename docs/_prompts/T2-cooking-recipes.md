### 配方清单（`needs` 用 `[材料ID, 数量]`，全部 `bench: 'food'`）

1. `稻粒×4 → 面粉×1`（**我补的引子配方**：用户原始设定「10 麦粒 + 1 面粉 → 8 面粉」是死循环，没有第一袋面粉永远开不了工；4 稻粒磨 1 袋是种子来源，别改这个数）
2. `稻粒×10 + 面粉×1 → 面粉×8`
3. `面粉×2 → 面团×1`
4. `熟肉×2 → 火腿×1`
5. `面团×1 + 稻粒×1 → 法式面包棍×1`
6. `法式面包棍×1 + 草×1 + 树叶×1 + 蘑菇×4 → 法式三明治×1`
7. `南瓜片×3 + 面团×1 → 南瓜饼×1`
8. `河豚×1 + 金针菇×1 → 河豚汤×1`
9. `小丑鱼×1 + 平菇×1 → 煎小丑鱼×1`
10. `鲑鱼×1 + 金针菇×1 → 炖鲑鱼×1`
11. `鳕鱼×1 + 平菇×1 → 炸鳕鱼排×1`
12. `面团×1 + 熟肉×1 → 肉夹馍×1`
13. `树叶×1 + 稻粒×32 → 竹筒饭×1`
14. `面团×1 + 树叶×1 + 熟肉×1 + 胡萝卜×1 → 胡萝卜肉饺×3`
15. `面粉×3 + 草×1 + 胡萝卜×1 → 胡萝卜蛋糕×1`
16. `平菇×1 + 胡萝卜×3 → 胡萝卜炒蘑菇×1`

「生菌汤」= **任意蘑菇×2**（香菇 292 / 金针菇 293 / 平菇 294 / 红伞伞 295 / 夜光蓝菇 298 任选 2 个，可同类可不同类）：用现有 `FRUITS.map(...)` 那种枚举展开手法写成 15 条组合（5 种取 2 可重复 = 15 条），只有**第一条进手册，其余 `quiet: true`**。

## 验收标准

1. `npm run build` 通过
2. 进游戏：4 稻粒在美食工作台 → 面粉；10 稻粒 + 1 面粉 → 8 面粉；2 面粉 → 面团；链条能一路做到 16 样东西
3. 生菌汤：香菇×2 / 香菇+红伞伞 / 平菇+夜光蓝菇 等任意两种蘑菇都能做，只成功一次
4. 每道料理吃掉：饥饿/血量变化与上表一致；河豚汤吃完 10 秒内移速变快；胡萝卜蛋糕吃完 15 秒里缓慢回血 2 点
5. 面粉和面团：背包里点「吃」没反应；收购箱不收（没价格）
6. 所有新料理进收购箱按上表价收；手册「食物」页能看到 14 条新料理 + 生菌汤 1 条
7. 普通工作台 / 2×2 背包：上述所有配方一个都合不出来
