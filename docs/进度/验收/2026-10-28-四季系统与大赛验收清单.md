## 怎么用这份清单

- 每一项都按 **操作 → 预期** 写，逐条打勾就行
- 发现不对的地方，记下「现象 + 复现步骤 + 想看到什么」，我按条目改
- 线上地址 `https://ms.7shu.asia/`，改完代码后我会重新构建部署；**验收时先 Ctrl+F5 强刷**（`index.html` 可能被缓存，旧页面会加载旧 bundle）

## 准备工作

- 存档改月份（验收四季相关项要用）：浏览器 F12 → Application → Local Storage → 找到存档键（键名里带 `save`）→ 把 JSON 里的 `date` 改成目标月份（如 `{m:9,d:5}` 是 9 月 5 日）→ 刷新页面
  - 四季口径：12/1/2 月 = 冬、3~5 = 春、6~8 = 夏、9~11 = 秋
- 要给东西：用创造模式进游戏，创造面板里都能直接拿（新增的柳树、花瓣、枫叶、七件套、节日道具、CS 道具都在面板里）
- 岛币：在大厅收购箱卖点东西，或用管理台发放
