## 怎么用这份清单

- 每一项都按 **操作 → 预期** 写，逐条打勾就行
- 发现不对的地方，记下「现象 + 复现步骤 + 想看到什么」，我按条目改
- **本批改动只在本地，还没部署线上**：本地验收用 `npm run server` + `npm run dev` 开 `http://localhost:5174/`；要线上验就先喊我部署，然后照旧 `https://ms.7shu.asia/` + Ctrl+F5 强刷

## 准备工作

- 给东西：创造模式进游戏，面板里能直接拿（菖蒲叶/护盾/香囊/三种召唤弓/药水瓶都在）
- 改日期/星期：浏览器 F12 → Application → Local Storage → 存档键 → 改 JSON 里的 `date`（口径同上一份清单：`{m,d}`）；改**游戏内时刻**直接睡床跳时段
- 快速磨护盾耐久：让僵尸多挠几下即可；想一次看碎盾效果，可以把装备耐久字段改小再进游戏
- 岛币：大厅收购箱卖点东西，或管理台发放

## 二、白萝卜买入/回收双价

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 存档日期改到**周一**，开黑色售卖机 | 有白萝卜进货行，价格在 **4~10 币**之间 |
| 2.2 | 换个账号看同一天的进货价 | 数字**不一样**（按账号名+日期摇号） |
| 2.3 | 退出重进再看 | 同账号同一天**价格不变**（种子固定） |
| 2.4 | 买几个萝卜，看回收行 | 回收价在 **2~12 币**之间，和进货价**不是同一个数** |
| 2.5 | 存档改到周二，开黑色售卖机 | 进货行**消失**（只能回收）；回收价变成 2~12 里的另一个数 |
| 2.6 | 改到下周三、周四…多看几天 | 每天回收价都在 2~12 内跳 |
| 2.7 | 下周一还没卖 | 萝卜**全部烂掉**（回归项，机制没动） |
| 2.8 | 按 7 开手册搜「白萝卜」 | 文案写的是**「4~10 随机」进货、「2~12 随机」回收**（不再是 50~666） |

## 三、药水扣饥饿

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 生存模式按 **O 开饥饿**，喝下毒药瓶 | 15 秒效果期间，除了正常消耗**额外**掉 **1 格**饥饿（15 秒 → 1 次） |
| 3.2 | 喝**水下呼吸瓶**（60 秒） | 60 秒里额外掉约 **6 格**饥饿（效果长扣得多，很直观） |

| 3.4 | 再按 **O 关掉饥饿**，喝任意药水 | **不掉**（饥饿开关关闭时暂停一切消耗，包括药水扣的） |
| 3.5 | 创造模式喝药 | 不掉 |
