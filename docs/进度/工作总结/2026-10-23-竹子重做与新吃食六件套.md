## 一、竹子重做

用户拿一张 MC 原版竹子渲染图做参照，要求「用代码实现，不能拿图片当素材」。两轮迭代后定稿，提交 `5655595`。

**造型**
- 竹竿从 4/16 收到 **3/16**（`Shapes.ts` 的 `BAMBOO_COLUMN`），碰撞盒同步收窄，杆子四周能走过去
- 竹节处新增 `BAMBOO_NODE_RING`（4/16 一圈），由 `ChunkMesher` 用 `bamboo_node` 贴图单独画，碰撞盒不算它
- 侧面贴图改成低对比竖纹 + 三道竹节横带（暗箍在下、亮边在上）；杆顶截面留空心
- 竹叶只长**梢头两节**（顶上一大丛 `bamboo_leaves`、顶下一节一小丛 `bamboo_leaves_small`），画法是「叶片打点进 16×16 栅格 → 统一描暗边 + 左上补光」，叶根分列杆子两侧（贴图中线正好被杆子挡住）
- 叶丛加宽到 1.24 格（`config.ts` 的 `BAMBOO_FX.LEAF_SPAN`）并钉在格子正中不抖动

**落地规则**（新增 `world/bamboo.ts`，三处共用同一份判断）
- `place()` 拒绝悬空种植并提示「竹子要种在泥土或草地上」
- `World.setBlock` 加 `fellBamboo()`：脚下被挖走/换掉时整根逐节塌掉
- `PlayerActions` 挖断中间一节时，上面几节用 `bambooAbove()` 先数好，照数进包
- `TerrainGen` 的竹林判定改用 `canRootIn()`

**部署**：旧 dist 备份到 `/root/mc-backup/dist-20261023/`，上传后清掉线上两个旧 `main-*.js` 残留，重启 `minecraft-web`，公网 `https://ms.7shu.asia/` 返回 200，线上 bundle 能 grep 到 `bamboo_node`。

## 二、P10 新吃食与效果框架

用户口述下发的六件套全部落地，提交 `93fb6f1`。数据单独放 `world/blocks.food.ts`（ID 309~314），避免继续撑大已超红线的 `blocks.data.ts`。

| 物品 | 配方 | 效果 |
|---|---|---|
| 红花蜜茶 | 小红花 + 玻璃瓶 | +1 饥饿，6 秒缓慢回 2 血 |
| 蒲公英凉茶 | 蒲公英×3 + 玻璃瓶 | +1 饥饿，解毒 |
| 草饼 | 杂草 + 稻粒 | +2 饥饿 |
| 颠倒香蕉液 | 香蕉×2 + 玻璃瓶 | +1 饥饿，8 秒方向反转 |
| 水果拼盘 | 五种水果各一 | +5 饥饿，6 秒移速×1.3 + 挖掘×1.5 + 缓慢回 2 血 |
| 蘑菇拼盘 | 四种好蘑菇各一 | +4 饥饿，6 秒移速×1.3 + 柔光照明 |

**框架改动**
- `FoodEffect` 扩了 `slowHeal / hasteSeconds / flipSeconds / glowSeconds / curePoison`
- `Health` 加 `slowHeal()`（按每秒速率攒够 1 点再回，不出小数血）与 `curePoison()`（`TimedEffects.clear()` 改为返回清掉几份）
- `PlayerBody` 加 `hasteT / flipT`，`Physics` 每帧递减，`flipT > 0` 时前进/后退、左右平移、键盘转向全部取反；`MouseLook` 与 `TouchControls` 的水平转向同步取反
- 挖掘加速叠在 `PlayerActions.updateMining` 的金镐倍率上
- 收购箱对自制吃食按「名义价 × 半价」回收（`Shop.CRAFT_FOOD_PRICE`），不进货架

## 三、顺带修掉的两个 bug

**1. 小战士在大厅召唤后回岛消失**
根因在 `Game.saveNow()`：非本岛时走 `saveCarryOnly()`，那条分支只并背包/岛币/血氧，**不写 `warriors`**，而 `summonWarrior()` 末尾那句 `saveNow()` 正好落在这条路上。改成非本岛召唤走新的 `persistWarrior()`，往本岛档追加 `pending: true` 条目；`applySave` 见 pending 就用 `pendingWarriorSpot()` 在出生点附近找两格空气放出来。三档血量同时按用户要求各 ×3：36 / 72 / 108。

**2. 木台阶永远做不出来**
全量扫了 111 条配方，发现木台阶和木棍都是「3 木板」，木棍排在前面抢走匹配。改成 1 木板出 2 台阶（与 MC 3 木板出 6 台阶同比例），现在 0 条配方做不出来。灯类（芒能灯/星能灯/氢能灯）核实配方与手册条目都在。

**雪块贴图**：照参考图用代码画了 11×11 六芒雪花（六条臂各带两对分叉）+ 四角小方块，远看是白雪、近看有浮雕。
