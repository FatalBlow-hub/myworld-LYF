## 踩坑记录

1. **注入测试存档要在进本地菜单之前**：本地菜单构建时 `listSaves()` 就把存档快照读进内存，点「继续」用的是旧快照，之后注入必被覆盖。正确顺序：登录页注入 → 进菜单 → 继续。
2. **内嵌浏览器 rAF 会被渲染节流冻住**：页面隐藏/遮挡后 `requestAnimationFrame` 完全停发，游戏 tick 死掉，一切按键无响应；`document.visibilityState` 却仍是 visible，极具迷惑性。三次唤醒尝试（visibility.set / tabs.get 激活 / 真实点击）均无效，属宿主环境限制。后续夜里验收若再遇到，直接换无头 Playwright 起独立浏览器跑，别在内嵌面板上耗轮次。
3. **用 textContent 判断暂停/弹窗状态不可靠**：隐藏元素的文字仍在 `#hud` 文本里，产生了多次假阳性；必须查 `getComputedStyle(el).display`。
4. **vite preview 与 vite dev 端口之争**：第一次起的 preview 一直占着 5174，后来 `vite --strictPort` 静默失败（日志落在临时文件里没看），误以为在跑 dev。好在 preview 服务的也是最新 dist，结论没错，但流程上应先 `netstat` 确认端口归属。
5. **页面卸载会触发自动存档**：游戏跑着时改 localStorage 再刷新，卸载时的存档会把注入冲掉——注入必须趁页面停在菜单/登录态做。
