登录页改版原型 v2 — 本机账号头像选择

相对 v1：头像升级全身像；去掉登录/注册页签（主流程只有「进入游戏」）；页面按状态下菜——顶部小按钮可切换「本机有账户 / 新设备」两种场景。交互可点：选头像、眼睛、展开其他账号/注册、记住此设备。

桌面版（主站 ms.7shu.asia）
手机版（m.7shu.asia / ?touch=1）
设计说明（确认后我再动真代码）：
  1. 头像就是游戏里的 3D 小人（正方形「头 + 肩膀」特写）：直接用 entities/Character 的模型 + 背包预览同款机位灯光渲染（MeshLambert + 三灯），长相、光影与游戏里 100% 一致；真实现时登录页每个头像挂一个 CharacterPreview 小画布（需把它的 76×132 竖屏尺寸/机位参数化出方框版，停渲染时零开销），不预制图、不加包体（three 本来就在包里）。
  2. 状态自适应：本机登录过的账号（浏览器本地记录）≥1 个 → 头像行是主角，点选后输密码进游戏；一个都没有 → 直接是注册表单，不摆空头像行骗人。
  3. 没有"两个登录按钮"了：v1 的页签已删。主流程唯一确认按钮叫「进入游戏」；「注册新账号 / 用其他账号登录」是底部小链接，点开才出表单。
  4. 记住此设备：勾上后，下次打开登录页点头像直接进游戏（服务端 device_tokens 换长期登录态；封停/删账号时令牌一并作废）。公共电脑别勾。
  5. 「不登录，玩本地存档」在游客开关（GUEST_PLAY，默认关）关闭时整行不渲染；原型用虚线框标注它"默认不存在"。
